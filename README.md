# SEJARAHVERSE FORM 2
## Demo: Misi Warisan Johor Riau

Prototaip permainan web pendidikan Sejarah Tingkatan 2.

### Cara cuba
1. Buka fail `index.html`.
2. Masukkan nama dan kelas.
3. Bergerak menggunakan WASD / anak panah atau butang pada telefon.
4. Dekati NPC dan tekan `E`, bar ruang atau butang `TINDAKAN`.

### Cara terbitkan di GitHub Pages
1. Cipta repository baharu, contohnya `sejarahverse-form2`.
2. Muat naik `index.html`, `style.css` dan `game.js`.
3. Pergi ke **Settings > Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/root`.
5. Simpan. Pautan permainan akan tersedia selepas beberapa minit.

### Kandungan demo
- Peta Kota Johor Lama
- Kawalan komputer dan telefon
- NPC Bendahara, Pedagang dan Sultan
- Kutipan syiling
- Misi berperingkat
- Pertempuran kuiz
- Markah, XP dan syiling
- Keputusan disimpan sementara dalam pelayar menggunakan `localStorage`
